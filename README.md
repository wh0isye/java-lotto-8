# java-lotto-precourse

## 1단계: 도메인 모델 구현
- [ ] **Lotto**
  - [ ] 1~45 범위의 중복되지 않은 6개 숫자로 로또 객체 생성
  - [ ] 번호 유효성 검사 (개수, 범위, 중복)
  - [ ] 당첨 번호와 일치하는 개수 반환
  - [ ] 보너스 번호 포함 여부 반환
- [ ] **Rank (Enum)**
  - [ ] 일치 개수 및 보너스 여부에 따른 Rank 반환
  - [ ] 각 Rank별 상금 및 조건 저장

---

## 2단계: 당첨 번호 및 결과 객체 구현
- [ ] **WinningLotto**
  - [ ] 당첨 번호 6개와 보너스 번호 1개 저장
  - [ ] 번호 유효성 검사 (개수, 범위, 중복)
  - [ ] 보너스 번호가 당첨 번호와 중복되지 않도록 검증
- [ ] **LottoResult**
  - [ ] 등수별 당첨 횟수 계산 기능
  - [ ] 총 당첨금 계산 기능
  - [ ] 수익률 계산 기능 (소수점 둘째 자리 반올림)

---

## 3단계: Controller 구현
- [ ] **LottoController**
  - [ ] 구입 금액 입력 및 유효성 검증 (1000원 단위)
  - [ ] 금액에 따라 로또 자동 발행
  - [ ] 구매한 로또 번호 출력
  - [ ] 당첨 번호 및 보너스 번호 입력 처리
  - [ ] 결과 계산 및 수익률 출력
  - [ ] 예외 발생 시 [ERROR] 메시지 출력 후 재입력 요청

---

## 4단계: View 구현
- [ ] **InputView**
  - [ ] 구입 금액 입력 받기
  - [ ] 당첨 번호 입력 받기
  - [ ] 보너스 번호 입력 받기
- [ ] **OutputView**
  - [ ] 발행한 로또 목록 출력
  - [ ] 당첨 통계 및 수익률 출력
  - [ ] [ERROR] 메시지 출력

---

## 5단계: 예외 처리 및 테스트
- [ ] **예외 처리**
  - [ ] IllegalArgumentException, IllegalStateException을 통한 명확한 오류 관리
  - [ ] “[ERROR]”로 시작하는 에러 메시지 출력 후 재입력 요청
- [ ] **단위 테스트 (JUnit5 + AssertJ)**
  - [ ] LottoTest: 번호 유효성 및 중복 검사 테스트
  - [ ] RankTest: 등수 매핑 검증
  - [ ] LottoResultTest: 수익률 계산 검증
  - [ ] WinningLottoTest: 보너스 번호 검증
  - [ ] LottoControllerTest: end-to-end 흐름 검증

---

## ⚙️ 예외 상황 정의

| 예외 상황                 | 예외 메시지                               |
| :-------------------- | :----------------------------------- |
| 구입 금액이 1,000원 단위가 아님  | `[ERROR] 구입 금액은 1,000원 단위여야 합니다.`    |
| 구입 금액이 숫자가 아님 또는 0 이하 | `[ERROR] 구입 금액은 양의 정수여야 합니다.`        |
| 로또 번호가 6개가 아님         | `[ERROR] 로또 번호는 6개여야 합니다.`           |
| 로또 번호가 1~45 범위를 벗어남   | `[ERROR] 로또 번호는 1부터 45 사이여야 합니다.`    |
| 로또 번호 중복 발생           | `[ERROR] 로또 번호는 중복될 수 없습니다.`         |
| 보너스 번호가 1~45 범위를 벗어남  | `[ERROR] 보너스 번호는 1부터 45 사이여야 합니다.`   |
| 보너스 번호가 당첨 번호와 중복됨    | `[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.` |
| 입력 형식 오류 (쉼표, 공백 등)   | `[ERROR] 잘못된 입력 형식입니다.`              |
